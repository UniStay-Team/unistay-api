# UniStay API

Backend общей платформы поиска жилья для студентов. Ответственный — Алмас. Репозиторий принадлежит UniStay-Team; основная ветка — main.

**Состояние:** стартовая документация и контракт. C# solution, сервер, миграции и тесты ещё не созданы. Backend пишется с нуля на ASP.NET Core / EF Core / PostgreSQL; прежний серверный код сюда не переносится.

## С чего начать

1. Прочитать [AGENTS.md](AGENTS.md), [ТЗ](docs/project-plan.md) и [структуру реализации](docs/implementation-guide.md).
2. Сверить [публичный контракт](docs/public-api-v1.md) и [OpenAPI baseline](docs/public-api-baseline.yaml) с Flutter.
3. Реализовать [admin API](docs/admin-api-v1.md) в рамках D0, затем V1.
4. Создать solution с UniStay.Api, UniStay.Application, UniStay.Core и тестами; согласовать версии .NET/EF Core/Npgsql и сохранить их в проекте.
5. Добавить реальные команды restore/build/test/run, PostgreSQL, миграции, demo-seed и пример настроек без секретов в этот README.

## Работает сейчас

Подготовлены ТЗ, правила совместной работы и схемы запросов/ответов. Запускаемого API пока нет. Baseline является спецификацией и не доказывает существование маршрутов.
